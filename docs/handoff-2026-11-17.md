## 7. Working rules this project follows (they were in the original machine's assistant memory, not in the repo)

- Decide single-user edition vs team hub first for every feature; the single-user path never needs a terminal; on a team hub, approvals stay on the member's own PC.
- Test-first; each worker edits only its own files; the full suite once at the end (`gofmt -l`, `go build`, `go vet`, `go test ./...` alone, web `tsc -b`, `check:api-imports`, `vitest run`, `npm --prefix desktop test`).
- Every UI string in `web/src/i18n.ts`, en and zh-TW (Taiwan usage); plain words in Simple mode (`i18nPlainWords.test.ts`).
- Postgres only (no SQLite); migrations append-only.
- Theme packs carry no third-party logos; Nodevas itself carries no character art; with a pack active, pictures replace text clutter.
- GitHub: squash merge only; master is ruleset-protected (no force push); push with `git -c credential.helper= -c credential.helper='!gh auth git-credential' push`; merge with `gh pr merge N --squash --match-head-commit <full sha>`.
- Shipped plans are deleted from the repo; deliverables the owner reads go where they can open them.
- Replies to the owner in terse Traditional Chinese; code, commits and PRs in English.
