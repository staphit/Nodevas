# 主題包

主題包可以用你自己的圖取代 Nodevas 內建的像素小人。它是一個 zip，裡面只有圖片、可能有幾段短片，以及一個 JSON 檔：不會執行任何程式，匯入也不用重啟或改啟動設定。

> **目前狀態：** 選用主題包後，Agent 動態會變成一段故事。側邊列出六個可以前往的地點：`work`、`meeting`、`entrance`、`lounge`、`away`、`runners`。舞台上是所選地點裡每個人的主題包圖片，每個角色的每種狀態一張；共用同一張圖的 agent 會站成一個，並標上 ×N。在對話框裡，你面向的 agent 會說它正在做什麼，你用選項回應，這些選項就是像素房間選單裡的那些動作。沒有角色符合的 agent 會以「未命名」的剪影出現，除非主題包有 `fallback` 角色。沒有選用主題包時，照舊畫出像素房間。下面的 zip 格式在匯入時就會檢查。

## 用自己的圖做主題包

圖可以來自任何工具：本機模型、線上生成服務或繪圖軟體都行。

### 1. 畫房間

每間房都畫成相同尺寸，裡面不要有人。這個尺寸就是 `canvas`，例如 1536×864。之後同一間房才能放進好幾個人。

### 2. 畫人物

每個人的每種狀態各一張：看書、睡覺等等。每張都要是透明背景的 `.png` 或 `.webp`，而且只有人物。這樣做，人物最能融入房間：

1. 先在單色背景上生成全身的人物，再去背。
2. 把人物貼到空房間裡想要的位置和大小。
3. 只重繪那一塊，強度約 45%，讓人物吃到房間的光線。
4. 把變動的部分連同柔和的邊緣存成透明圖，並記下它在房間裡的位置，這就是 `x`、`y`、`w`、`h`。

選位置時別讓人物互相遮住，每個人的姿勢也要不一樣，否則同一間房看起來會像同一個人的複製品。

人物也可以直接畫成一整張圖，連周圍的環境一起畫好；這兩種圖都可以做成會動的，也可以換成短片。做法見下面的「整張圖、動態和標記」。

### 3. 整理資料夾

```text
my-pack/
  theme.json
  rooms/
    lounge.webp
  figures/
    claude/
      read.webp
  pictures/
    claude/
      idle.webp
      write.webp
      write.webm
      write-click.webm
  signs/
    mage.webp
```

資料夾名稱可以自己取。唯一固定的是 `theme.json`，它必須在 zip 的最上層。其他檔案都必須寫在 `theme.json` 裡，所以記得刪掉 `Thumbs.db`、`.DS_Store` 這類多餘的檔案：只要多一個檔案，整個 zip 就會被拒絕。

### 4. 寫 theme.json

```json
{
  "schema": 1,
  "name": {"en": "My pack", "zh-TW": "我的主題"},
  "version": "1.0.0",
  "author": "your name",
  "canvas": [1536, 864],
  "rooms": {
    "lounge": "rooms/lounge.webp"
  },
  "characters": {
    "claude": {
      "match": {"agents": ["claude"], "models": ["claude*"]},
      "sign": "signs/mage.webp",
      "title": {"en": "The Sage", "zh-TW": "賢者"},
      "lines": {
        "idle": {"en": "The hearth is warm.", "zh-TW": "爐火正暖。"}
      },
      "scenes": {
        "read": {
          "room": "lounge",
          "image": "figures/claude/read.webp",
          "x": 217, "y": 147, "w": 408, "h": 699,
          "box": [243, 170, 598, 810]
        },
        "idle": {
          "image": "pictures/claude/idle.webp",
          "x": 0, "y": 0, "w": 1536, "h": 864,
          "box": [520, 180, 1010, 864],
          "frames": {"count": 4, "blink": 1, "click": [2, 3]},
          "sign": [765, 120, 96]
        },
        "write": {
          "image": "pictures/claude/write.webp",
          "video": "pictures/claude/write.webm",
          "clickVideo": "pictures/claude/write-click.webm",
          "x": 0, "y": 0, "w": 1536, "h": 864,
          "box": [520, 180, 1010, 864],
          "sign": [765, 120, 96]
        }
      }
    }
  },
  "skin": {
    "scheme": "dark",
    "font": "serif",
    "colors": {"bg": "#0d0e1c", "surface": "#15142b", "text": "#efe6d0", "accent": "#d9b86c"}
  },
  "places": {
    "work": {"en": "Study", "zh-TW": "書房"},
    "lounge": {"en": "Hearth", "zh-TW": "爐邊"}
  },
  "words": {
    "narrator": {"en": "Chronicler", "zh-TW": "史官"},
    "task": {"en": "a quest", "zh-TW": "一項委託"}
  },
  "lines": {
    "working": {"en": "I am casting on {node}.", "zh-TW": "我正在對 {node} 施法。"}
  }
}
```

| 欄位 | 意思 | 規則 |
| --- | --- | --- |
| `schema` | 格式版本 | 固定是 `1` |
| `name` | 設定頁顯示的名稱。`en` 也用來識別主題包：用相同名稱再次匯入會取代你原本的主題包 | `en` 必填，只能用英文字母和數字，其中字母和數字最多 40 個；`zh-TW` 選填；各最多 64 個字元；不能是 `none` 或 `default` |
| `version` | 你自己的版本 | 1 到 64 個字元 |
| `author` | 作者 | 最多 64 個字元 |
| `canvas` | 每間房和每張整張圖的寬和高 | 兩個 1 到 8192 的整數 |
| `rooms` | 房間代號 → 圖片。沒有場景指定房間時可以不寫 | 代號規則見下方 |
| `characters` | 角色代號 → 它的 `match` 和 `scenes` | 代號規則見下方 |
| `match.agents` | 這個角色代表哪些 agent：`claude`、`codex`（GPT）、`gemini`、`opencode`、`antigravity` | 最多 16 項 |
| `match.models` | 這個角色代表哪些模型，`*` 預定當萬用字元 | 最多 16 項，每項最多 64 個字元 |
| `fallback` | 選填。設成 `true`，這個角色就會代表沒有其他角色符合的 agent | 一個主題包最多一個 |
| `sign`（角色） | 選填。飄在她頭上的標記所用的圖片 | 必須在 zip 裡 |
| `title` | 選填。這個角色在對話框名牌上的稱號 | 見下面的「用語和台詞」 |
| `lines`（角色） | 選填。這個角色在對話框裡說的話 | 見下面的「用語和台詞」 |
| `scenes` | 場景名稱 → 這個角色的一張圖 | 名稱規則見下方 |
| `room` | 這個場景發生在哪間房。選填：不寫的話，`image` 就是整張圖，底下不會畫任何東西 | 有寫就必須在 `rooms` 裡 |
| `image` | 人物的透明圖，或是整張圖 | 必須在 zip 裡 |
| `x`、`y`、`w`、`h` | 圖片填滿的矩形，單位是畫布像素；`w` 和 `h` 請和圖片本身的尺寸相同 | 整數，要在畫布內 |
| `box` | 人物在畫布內的左、上、右、下，是預定拿來點選的範圍 | 要在畫布內，左 < 右，上 < 下 |
| `frames` | 選填。讓 `image` 變成一條影格，可以眨眼，也會回應點擊 | `count` 是 2 到 16；`blink` 和最多 4 個 `click` 影格，都要是 1 到 `count` − 1 |
| `video` | 選填。取代 `image` 播放的短片，無聲、循環；`image` 仍是靜止的畫面 | `.mp4` 或 `.webm`，必須在 zip 裡；不能和 `frames` 同時使用 |
| `clickVideo` | 選填。點她的時候播放一次的短片，無聲；播完回到循環短片或靜止的畫面 | `.mp4` 或 `.webm`，必須在 zip 裡；不能和 `frames` 同時使用；有沒有 `video` 都可以 |
| `sign`（場景） | 選填。`[x, y, width]`：角色的標記在這張圖上的中心位置，以及要畫多寬，單位是畫布像素 | 要在畫布內，寬度大於 0；角色必須有 `sign` 圖片 |
| `skin` | 選填。整個 app 的配色，不只Agent 動態 | 見下面的「配色」 |
| `places` | 選填。你為Agent 動態各個地點取的名稱 | 見下面的「地點名稱」 |
| `words` | 選填。故事介面上改用你的用語 | 見下面的「用語和台詞」 |
| `lines` | 選填。agent 在對話框裡說的話 | 見下面的「用語和台詞」 |

房間代號、角色代號和場景名稱都用小寫字母、數字、`_` 和 `-`，最多 64 個字元。比對名稱時會忽略 `name.en` 裡的標點和空白，所以 `Magic world` 和 `magic-world` 算同一個主題包。如果別人已經匯入這個名稱，請改你的名稱。一個主題包最多 256 間房、64 個角色，每個角色最多 256 個場景。任何地方出現未知欄位都會拒絕整個 zip，這樣打錯字也抓得到。

場景名稱依 agent 正在做的事分類：

| 情境 | 名稱 |
| --- | --- |
| 工作中 | `read`、`search`、`think`、`write`、`cast` |
| 等你處理或已結束 | `wait`、`ask`、`done`、`fail` |
| 休息 | `idle`、`sleep` |
| 開會 | `listen`、`speak` |
| 外出 | `hike`、`stream`、`fish`、`camp`、`bbq`、`ride` |

### 5. 壓縮

要壓縮資料夾裡的內容，不是資料夾本身，否則 `theme.json` 就不在最上層。在 `my-pack` 裡執行：

```shell
python -m zipfile -c ../my-pack.zip theme.json rooms figures pictures signs
```

不要用 PowerShell 的 `Compress-Archive`：舊版會在路徑裡寫入反斜線，而反斜線會讓 zip 被拒絕。

### 6. 匯入

打開 **設定 → 一般 → 主題包**，按 **匯入 zip**，再到 **我的主題** 選你的主題包。如果 zip 被拒絕，訊息會說明要修什麼，原本相同名稱的主題包也會繼續正常運作。

同一台 server 上的其他人都能在清單裡看到並選用你的主題包，所以它不是私人的。不過只有對方自己選用，或管理員設成全站預設，他們的畫面才會套用。你可以刪除自己的主題包，管理員可以刪除任何主題包。

## 整張圖、動態和標記

房間加去背人物是一種做法。另一種是整張圖：每種狀態一張完成的圖，人物已經畫在她的環境裡。主題包可以只用其中一種，也可以像上面的範例那樣混用。

### 整張圖

場景不寫 `room`，它的 `image` 就會單獨畫出來，底下沒有房間。只有整張圖的主題包完全不需要 `rooms`。`x`、`y`、`w`、`h` 一樣是圖片在畫布上的位置，通常就是整個畫布：`0`、`0` 加上畫布尺寸。`box` 一樣是人物在圖裡的範圍。

### 動態

`frames` 會把場景的 `image` 當成一條影格：`count` 個影格由左到右並排，每格 `w`×`h` 像素，所以檔案寬 `count` × `w`、高 `h`。範例裡的 `idle` 是一個 6144×864 的檔案，裡面有四格 1536×864。房間裡的去背人物也可以用 `frames`。

| 部分 | 意思 |
| --- | --- |
| 第 0 格 | 最左邊那格：靜止的畫面，一直都會畫 |
| 其他每一格 | 只留有變動的地方，例如閉上的眼睛或舉起的手，其餘透明。它會疊在第 0 格上面 |
| `blink` | 不時自己播一下的那一格 |
| `click` | 點她的時候依序播放的影格，最多 4 個 |

`blink` 和 `click` 都是選填，而且從 1 算起，因為第 0 格是靜止的畫面。同一格可以兩種用途都給。一條影格是一張圖片，所以所有影格加起來受 16 MiB 的限制。匯入時不會打開圖片檢查，寬度不對的影格條一樣會通過，只是畫出來會錯：請自己確認寬度是 `count` × `w`。

### 短片

`video` 指定一段短片，取代場景的 `image` 播放：無聲、循環，而且只在畫面位於螢幕上或附近時播放。短片填滿場景的 `x`、`y`、`w`、`h`；場景有房間時疊在房間上面；形狀不同時會裁切，不會拉伸。範例裡的 `write` 就是一段整張圖的短片。

`image` 仍然必填，它是靜止的畫面：短片開始前、使用者的系統要求減少動態效果或頁面在背景分頁時、短片無法播放時，以及Agent 動態從圖裡裁出一塊的地方（例如對話框旁她的臉），都會顯示它。請用短片的第一格當 `image`，短片開始時畫面才不會跳。

有 `video` 的場景不能同時有 `frames`。請用 `.mp4` 裝 H.264，或 `.webm` 裝 VP9，每個瀏覽器才都能播放；音軌永遠不會播出。一段短片是一個檔案，所以必須在 16 MiB 以內。匯入時只檢查檔案開頭是否符合類型，所以後段損毀的短片會改顯示靜止的畫面。

`clickVideo` 指定她被點擊時的反應短片：從頭無聲播放一次，取代循環短片，播完再回到循環短片（沒有 `video` 的場景則回到靜止的畫面）。播放中再點一次會從頭重播。它填滿和 `video` 相同的矩形，只在畫面位於螢幕上或附近時才載入；使用者的系統要求減少動態效果或頁面在背景分頁時，點擊不會播放。請讓它從靜止的畫面開始，也停在靜止的畫面，前後畫面才不會跳。範例裡的 `write` 就有一段。有 `clickVideo` 的場景不能同時有 `frames`，因為 `frames` 有自己回應點擊的 `click` 影格。類型和 16 MiB 的限制都相同；無法播放的點擊短片會直接略過，循環短片照常播放。

### 標記

角色的 `sign` 是另外一張圖片：飄在她頭上的標記，例如代表她專長的徽章。只有自己也寫了 `sign` 的場景才會畫出它。場景的 `sign` 是 `[x, y, width]`，單位是畫布像素：標記的中心位置，以及要畫多寬。場景沒寫 `sign` 就不會顯示標記。角色沒有 `sign` 圖片，場景卻寫了 `sign`，整個 zip 會被拒絕。

## 配色

選用你的主題包時，`skin` 會改變整個 app 的配色，不只Agent 動態。不寫的話，app 維持原本的配色。

| 部分 | 意思 | 規則 |
| --- | --- | --- |
| `scheme` | 你的顏色以哪一套內建配色為底 | 必填：`light` 或 `dark` |
| `font` | app 的字體 | 選填：`sans` 或 `serif` |
| `colors` | 你要改的顏色，其餘沿用 `scheme` 的 | 選填。只能用下面的名稱，值必須是十六進位色碼：`#rgb`、`#rrggbb` 或 `#rrggbbaa` |

| 顏色 | 用在哪裡 |
| --- | --- |
| `bg` | 最底層的頁面背景 |
| `surface`、`surface-2` | 面板和卡片，以及嵌在裡面的區塊 |
| `border`、`border-strong` | 分隔線，淡的和明顯的 |
| `hover` | 滑鼠移到的項目 |
| `text`、`text-2` | 文字，以及次要的文字 |
| `accent`、`accent-text` | 按鈕和強調色，以及上面的文字 |

名稱不在這份清單裡，或值不是十六進位色碼（`red`、`rgb(0,0,0)`、`var(--x)`），整個 zip 會被拒絕。

## 地點名稱

`places` 讓Agent 動態的地點改用你主題包的名稱。六個地點可以只寫其中幾個，沒寫的沿用原本的名稱。

| 地點 | 是什麼 |
| --- | --- |
| `work` | agent 工作的地方 |
| `meeting` | 會議室 |
| `entrance` | 門口，等待接手的工作在這裡 |
| `lounge` | agent 休息的地方 |
| `away` | 額度用完、等待重置的 agent 去的地方 |
| `runners` | runner，也就是像素房間的機房 |

每個名稱的寫法和主題包的 `name` 一樣：`en` 必填，`zh-TW` 選填。各最多 40 個字元，不能有換行這類控制字元。地點不在這份清單裡，整個 zip 會被拒絕。

## 用語和台詞

主題包可以像上面的範例那樣，用自己的話來說這段故事。每段文字的寫法和主題包的 `name` 一樣：`en` 必填，`zh-TW` 選填，不能有換行這類控制字元。

| 欄位 | 意思 | 規則 |
| --- | --- | --- |
| `words` | 故事介面上各個用語，改用你的說法 | 只能用下面的用語。各最多 120 個字元 |
| `lines` | agent 在對話框裡說的話，依狀態分 | 只能用下面的狀態。各最多 200 個字元 |
| `lines`（角色） | 同上，但只給這個角色代表的 agent | 同 `lines` |
| `title`（角色） | 這個角色在對話框名牌上的稱號，例如「賢者」，顯示在 agent 自己的名稱前面 | 各最多 40 個字元 |

| 用語 | 用在哪裡 |
| --- | --- |
| `narrator`、`unnamed` | 沒有人在場時的名牌，以及沒有角色符合的 agent |
| `task` | agent 不在任何節點上時，台詞裡的 `{node}` 會換成它 |
| `people`、`notices`、`others` | 三份清單的名稱：在場的人、等你處理的事、其他辦公室 |
| `count`、`nobody`、`runnerCount`、`failed` | 地點旁的數量：有幾個人、沒有人、幾台 runner、幾個失敗。除了 `nobody`，都會帶入 `{count}` |
| `empty`、`noticesLine`、`runnersLine` | 旁白說的話：`{place}` 沒有人、有 `{count}` 件事等你處理、`{count}` 台 runner 上有 `{busy}` 個執行中 |
| `heldLine` | 有 `{count}` 則給 agent 的訊息等你核准時，它說的話 |
| `more` | 打開其餘選項的那個選項 |
| `status`、`role`、`node`、`runner`、`tokens`、`project`、`held`、`tests` | 你面向的 agent 各項資訊的標籤 |

台詞可以寫給這些狀態：`offline`、`asking-user`、`failed`、`limit`、`awaiting-accept`、`waiting-ci`、`reviewing`、`working`、`finished`、`idle`。

角色的台詞優先於主題包的，主題包的優先於 app 內建的。台詞裡可以寫 `{node}`：它會換成 agent 所在節點的標題並加上引號；agent 不在任何節點上時，換成你的用語 `task`，沒寫就用 app 自己的。用語或狀態不在這些清單裡，整個 zip 會被拒絕。

## 同時安裝多個主題包並切換

每個主題包的 `name.en` 取不同名稱再匯入，就會全部留著，每人最多 5 個。到 **設定 → 一般 → 主題包 → 我的主題** 切換：

| 我的主題 | 你看到的畫面 |
| --- | --- |
| 全站預設 | 管理員為全站選的主題包；沒有選就是內建小人 |
| 內建像素小人 | 不套用主題包 |
| 主題包名稱 | 那個主題包 |

選擇存在這個瀏覽器裡，所以其他瀏覽器或裝置要各自選，而且只影響你自己看到的畫面。匯入主題包不會自動選用它。

## 只替換一個角色

主題包不必包含所有角色。如果只想換 GPT，就寫一個角色，對應 GPT 使用的 agent 和模型。角色代號可以自己取，真正決定對應的是 `match`。GPT 的 agent 名稱是 `codex`：

```text
"characters": {
  "my-gpt": {
    "match": {"agents": ["codex"], "models": ["gpt*", "o1*", "o3*", "o4*"]},
    "scenes": { ... }
  }
}
```

要修改現有主題包裡的一個角色：換掉她的圖片；尺寸或位置有變，就更新 `x`、`y`、`w`、`h` 和 `box`；調高 `version` 後重新壓縮並匯入。相同的 `name.en` 會取代舊的主題包；改了 `name.en` 則會變成新的主題包，舊的會留著，直到你刪除它。

## 主題包如何對應到 agent

以下是Agent 動態畫主題包時遵守的規則。

| 情況 | 會顯示 |
| --- | --- |
| 這個 agent 是哪個角色？ | 先找 `match.models` 符合目前模型的角色，再找 `match.agents` 符合 agent 的角色。模型優先，因為它才代表實際是誰在做事：opencode 跑 GPT 模型就顯示 GPT |
| 沒有符合的角色 | 主題包的 `fallback` 角色；沒有就顯示「未命名」的剪影 |
| 這個角色缺這種狀態的圖 | 她的 `idle` 場景；沒有 `idle` 就顯示「未命名」的剪影 |
| 同一個角色有多個 agent 處於同一種狀態 | 站成一個，並標上 ×N |

## 限制

| 項目 | 上限 |
| --- | --- |
| 圖片類型 | `.webp`、`.png`、`.jpg`、`.jpeg`，副檔名要小寫，不支援 SVG |
| 短片類型 | `.mp4`、`.webm`，副檔名要小寫，而且只能當場景的 `video` 或 `clickVideo` |
| zip | 200 MiB |
| 單張圖片或單段短片 | 16 MiB |
| `theme.json` | 4 MiB |
| 主題包內的檔案數 | 2000 |
| 解壓後的總大小 | 500 MiB |
| 每人的主題包數 | 5 |
| server 上所有主題包 | 2 GiB |
| 路徑 | 用正斜線的相對路徑，最多 200 bytes；不能有 `..` 和 `\ : * ? " < > |`，名稱也不能以句點或空白結尾 |

每張圖片和每段短片的實際類型都必須和副檔名相符。用 `.webp` 可以把檔案壓得很小：12 間房加 76 張人物，大約 6 MB 就放得下。

## 權利

只匯入你有權使用的圖片，包括生成模型的授權，以及屬於他人的 logo 或角色。server 上的每個人都能讀取你匯入的主題包。
