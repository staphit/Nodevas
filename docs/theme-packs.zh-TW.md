# 主題包

主題包可以用你自己的圖取代 Nodevas 內建的像素小人。它是一個 zip，裡面只有圖片和一個 JSON 檔：不會執行任何程式，匯入也不用重啟或改啟動設定。

> **目前狀態：** 主題包已經可以匯入、列出和選擇，但戰情室還不會畫出主題包，所以選了之後畫面不會變。下面的 zip 格式在匯入時就會檢查；場景名稱和角色的對應方式，要等戰情室接上才算定案。

## 用自己的圖做主題包

圖可以來自任何工具：本機模型、線上生成服務或繪圖軟體都行。

### 1. 畫房間

每間房都畫成相同尺寸，裡面不要有人。這個尺寸就是 `canvas`，例如 1536×864。之後同一間房才能放進好幾個人。

### 2. 畫人物

每個人的每種狀態各一張：看書、睡覺等等。每張都要是透明背景的 `.png` 或 `.webp`，而且只有人物。這樣做，人物最能融入房間：

1. 先在單色背景上生成全身的人物，再去背。
2. 把人物貼到空房間裡想要的位置和大小。
3. 只重繪那一塊，強度約 45%，讓人物吃到房間的光線。
4. 把變動的部分連同柔和的邊緣存成透明圖，並記下它在房間裡的位置，這就是 `x`、`y`、`w`、`h`。

選位置時別讓人物互相遮住，每個人的姿勢也要不一樣，否則同一間房看起來會像同一個人的複製品。

### 3. 整理資料夾

```text
my-pack/
  theme.json
  rooms/
    lounge.webp
  figures/
    claude/
      read.webp
```

資料夾名稱可以自己取。唯一固定的是 `theme.json`，它必須在 zip 的最上層。其他檔案都必須寫在 `theme.json` 裡，所以記得刪掉 `Thumbs.db`、`.DS_Store` 這類多餘的檔案：只要多一個檔案，整個 zip 就會被拒絕。

### 4. 寫 theme.json

```json
{
  "schema": 1,
  "id": "my-pack",
  "name": {"en": "My pack", "zh-TW": "我的主題"},
  "version": "1.0.0",
  "author": "your name",
  "canvas": [1536, 864],
  "rooms": {
    "lounge": "rooms/lounge.webp"
  },
  "characters": {
    "claude": {
      "match": {"agents": ["claude"], "models": ["claude*"]},
      "scenes": {
        "read": {
          "room": "lounge",
          "image": "figures/claude/read.webp",
          "x": 217, "y": 147, "w": 408, "h": 699,
          "box": [243, 170, 598, 810]
        }
      }
    }
  }
}
```

| 欄位 | 意思 | 規則 |
| --- | --- | --- |
| `schema` | 格式版本 | 固定是 `1` |
| `id` | 主題包代號，用相同代號再次匯入會取代你原本的主題包 | 小寫字母、數字和 `-`，最多 40 個字元，不能是 `none` 或 `default` |
| `name` | 設定頁顯示的名稱 | `en` 必填，`zh-TW` 選填，各最多 64 個字元 |
| `version` | 你自己的版本 | 1 到 64 個字元 |
| `author` | 作者 | 最多 64 個字元 |
| `canvas` | 每間房的寬和高 | 兩個 1 到 8192 的整數 |
| `rooms` | 房間代號 → 圖片 | 代號規則見下方 |
| `characters` | 角色代號 → 它的 `match` 和 `scenes` | 代號規則見下方 |
| `match.agents` | 這個角色代表哪些 agent：`claude`、`codex`（GPT）、`gemini`、`opencode`、`antigravity` | 最多 16 項 |
| `match.models` | 這個角色代表哪些模型，`*` 預定當萬用字元 | 最多 16 項，每項最多 64 個字元 |
| `fallback` | 選填。設成 `true`，這個角色就會代表沒有其他角色符合的 agent | 一個主題包最多一個 |
| `scenes` | 場景名稱 → 這個角色的一張圖 | 名稱規則見下方 |
| `room` | 這個場景發生在哪間房 | 必須在 `rooms` 裡 |
| `image` | 人物的透明圖 | 必須在 zip 裡 |
| `x`、`y`、`w`、`h` | 圖片填滿的矩形，單位是畫布像素；`w` 和 `h` 請和圖片本身的尺寸相同 | 整數，要在畫布內 |
| `box` | 人物在畫布內的左、上、右、下，是預定拿來點選的範圍 | 要在畫布內，左 < 右，上 < 下 |

房間代號、角色代號和場景名稱都用小寫字母、數字、`_` 和 `-`，最多 64 個字元。一個主題包最多 256 間房、64 個角色，每個角色最多 256 個場景。任何地方出現未知欄位都會拒絕整個 zip，這樣打錯字也抓得到。

目前可用的場景名稱如下，戰情室接上前可能還會調整：

| 情境 | 名稱 |
| --- | --- |
| 工作中 | `read`、`search`、`think`、`write`、`cast` |
| 等你處理或已結束 | `wait`、`ask`、`done`、`fail` |
| 休息 | `idle`、`sleep` |
| 開會 | `listen`、`speak` |
| 外出 | `hike`、`stream`、`fish`、`camp`、`bbq`、`ride` |

### 5. 壓縮

要壓縮資料夾裡的內容，不是資料夾本身，否則 `theme.json` 就不在最上層。在 `my-pack` 裡執行：

```shell
python -m zipfile -c ../my-pack.zip theme.json rooms figures
```

不要用 PowerShell 的 `Compress-Archive`：舊版會在路徑裡寫入反斜線，而反斜線會讓 zip 被拒絕。

### 6. 匯入

打開 **設定 → 一般 → 主題包**，按 **匯入 zip**，再到 **我的主題** 選你的主題包。如果 zip 被拒絕，訊息會說明要修什麼，原本相同代號的主題包也會繼續正常運作。

同一台 server 上的其他人都能在清單裡看到並選用你的主題包，所以它不是私人的。不過只有對方自己選用，或管理員設成全站預設，他們的畫面才會套用。你可以刪除自己的主題包，管理員可以刪除任何主題包。

## 同時安裝多個主題包並切換

每個主題包用各自的 `id` 匯入，就會全部留著，每人最多 5 個。到 **設定 → 一般 → 主題包 → 我的主題** 切換：

| 我的主題 | 你看到的畫面 |
| --- | --- |
| 全站預設 | 管理員為全站選的主題包；沒有選就是內建小人 |
| 內建像素小人 | 不套用主題包 |
| 主題包名稱 | 那個主題包 |

選擇存在這個瀏覽器裡，所以其他瀏覽器或裝置要各自選，而且只影響你自己看到的畫面。匯入主題包不會自動選用它。

## 只替換一個角色

主題包不必包含所有角色。如果只想換 GPT，就寫一個角色，對應 GPT 使用的 agent 和模型。角色代號可以自己取，真正決定對應的是 `match`。GPT 的 agent 名稱是 `codex`：

```text
"characters": {
  "my-gpt": {
    "match": {"agents": ["codex"], "models": ["gpt*", "o1*", "o3*", "o4*"]},
    "scenes": { ... }
  }
}
```

要修改現有主題包裡的一個角色：換掉她的圖片；尺寸或位置有變，就更新 `x`、`y`、`w`、`h` 和 `box`；調高 `version` 後重新壓縮並匯入。相同的 `id` 會取代舊的主題包。

## 主題包如何對應到 agent

以下是戰情室之後會遵守的規則。它現在還不會讀取主題包，所以目前都還看不到實際效果。

| 情況 | 會顯示 |
| --- | --- |
| 這個 agent 是哪個角色？ | 先找 `match.models` 符合目前模型的角色，再找 `match.agents` 符合 agent 的角色。模型優先，因為它才代表實際是誰在做事：opencode 跑 GPT 模型就顯示 GPT |
| 沒有符合的角色 | 主題包的 `fallback` 角色；沒有就顯示內建像素小人 |
| 這個角色缺這種狀態的圖 | 她的 `idle` 場景；沒有 `idle` 就顯示內建像素小人 |
| 同一間房有多個人 | 各自照 `x`、`y` 擺放，系統不會幫忙錯開，所以請自己避免重疊 |

## 限制

| 項目 | 上限 |
| --- | --- |
| 圖片類型 | `.webp`、`.png`、`.jpg`、`.jpeg`，副檔名要小寫，不支援 SVG |
| zip | 200 MiB |
| 單張圖片 | 16 MiB |
| `theme.json` | 4 MiB |
| 主題包內的檔案數 | 2000 |
| 解壓後的總大小 | 500 MiB |
| 每人的主題包數 | 5 |
| server 上所有主題包 | 2 GiB |
| 路徑 | 用正斜線的相對路徑，最多 200 bytes；不能有 `..` 和 `\ : * ? " < > |`，名稱也不能以句點或空白結尾 |

每張圖片的實際類型都必須和副檔名相符。用 `.webp` 可以把檔案壓得很小：12 間房加 76 張人物，大約 6 MB 就放得下。

## 權利

只匯入你有權使用的圖片，包括生成模型的授權，以及屬於他人的 logo 或角色。server 上的每個人都能讀取你匯入的主題包。
